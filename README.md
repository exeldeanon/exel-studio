# ⚡ Exel Studio — Ultimate AI Video Unique Engine v3.3

**Exel Studio** — мощное десктопное приложение для **массовой уникализации видеоконтента** с графическим интерфейсом. Идеально подходит для контент-мейкеров, SMM-специалистов и арбитражников, которым нужно создавать множество уникальных копий видео для загрузки на платформы (TikTok, Instagram Reels, YouTube Shorts) без получения теневых банов и дублей.

Приложение использует **FFmpeg** в качестве движка обработки и применяет десятки параметров рандомизации к каждому выходному файлу, делая каждую копию уникальной на уровне хеша, метаданных, визуальных и аудио-характеристик.

## 🚀 Возможности

### Визуальная уникализация
- **Crop & Zoom** — случайный зум и обрезка краёв в заданном диапазоне
- **Цветовые пресеты** — 10+ стилей цветокоррекции (TikTok Gloss, Cinematic Dark, Vintage Film, Neon Cyberpunk и др.)
- **Пикселизация** — настраиваемая интенсивность пиксельного эффекта
- **Шум (Noise)** — добавление визуального шума с рандомной интенсивностью
- **Зеркальное отражение (Flip)** — горизонтальное отражение видео
- **Jitter / Camera Shake** — эффект дрожания камеры
- **Fade-In** — плавное появление видео из чёрного
- **Рандомизация FPS** — каждая копия получает слегка отличающуюся частоту кадров

### Формат 9:16 с размытым фоном
- Автоматическое приведение любого исходного видео к вертикальному формату **1080×1920**
- Фон заполняется **размытой копией** оригинального видео (boxblur)
- Оригинальное видео размещается по центру поверх размытого фона

### Аудио-уникализация
- **Вариация скорости** — изменение скорости воспроизведения и тональности
- **Вариация громкости** — случайная громкость для каждой копии
- **Аудио-мутация** — мягкая эквализация (treble/bass) без питч-шока
- **Фоновый белый шум** — подмешивание тихого белого шума к аудиодорожке
- **Fade-In аудио** — плавное нарастание звука

### Вотермарки и оверлеи
- Наложение PNG/JPG водяных знаков и плашек
- Настройка **прозрачности**, **размера** и **позиции** (случайная, углы, центр)

### Метаданные и хеширование
- **Meta Scrub** — полная замена метаданных (имитация iPhone 16 Pro Max AVC encoder)
- **Hash Padding** — модификация файла для изменения MD5/SHA-хеша
- Удаление всех оригинальных метаданных (`-map_metadata -1`)

### Производительность
- **Многопоточный рендеринг** через `ThreadPoolExecutor`
- Поддержка **NVIDIA NVENC** (GPU-ускорение)
- Настраиваемое количество потоков CPU
- Прогресс-бар и логирование в реальном времени
- **Автосохранение** всех настроек в `studio_config.json`

## 🔧 Установка

### Вариант 1: Запуск из исходного кода

```bash

git clone https://github.com/YOUR_USERNAME/exel-studio.git
cd exel-studio

# 2. Создайте виртуальное окружение
python -m venv venv

# 4. Убедитесь, что FFmpeg установлен
ffmpeg -version

# 5. Запустите приложение
python app.py
```

### Вариант 2: Готовый EXE (Windows)

Скачайте `app.exe` из раздела [Releases](../../releases) и запустите.  
FFmpeg всё равно должен быть установлен в системе.

## 🔬 Как работает уникализация

Каждая выходная копия получает **уникальный набор параметров**, сгенерированный случайно в заданных диапазонах:

```
Исходное видео → Генерация случайных параметров → FFmpeg filter_complex → Кодирование → Уникальная копия ✅
```

**Фильтры FFmpeg для каждой копии:**
1. `split` → разделение на основной поток и фон
2. Фон → `scale` + `crop` + `boxblur` → размытый фон 1080×1920
3. Основной поток → crop + zoom + color + noise + pixelate + flip + jitter + fps + fade
4. `overlay` → наложение основного видео на размытый фон
5. Watermark overlay (если включён)
6. Аудиофильтры: atempo + volume + eq + afade + anoisesrc + amix
7. Кодирование: libx264/h264_nvenc + AAC 192k + faststart
8. Meta scrub + hash padding

**Результат:** уникальный MD5/SHA-хеш, отличающиеся метаданные, визуально неуловимые различия.

## ❓ FAQ

**Q: Нужен ли интернет?**  
A: Нет, приложение полностью офлайн.

**Q: Почему медленно?**  
A: Включите NVENC или уменьшите число потоков.

**Q: Можно ли обрабатывать не 9:16?**  
A: Да, любое соотношение автоматически приводится к 9:16 с размытым фоном.

**Q: Поддерживаются ли видео без звука?**  
A: Да, аудиодорожка определяется автоматически.

**Q: Как добавить свой цветовой пресет?**  
A: Откройте `app.py`, найдите `presets_pool` и добавьте FFmpeg-фильтр.
